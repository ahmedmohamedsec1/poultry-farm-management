تطبيق إدارة مزارع الدواجن - نسخة قابلة للتثبيت من المتصفح (PWA)

مهم:
- لا يمكن تثبيت التطبيق كـ PWA بفتح index.html مباشرة من مجلد التنزيلات.
- ارفع كل محتويات هذا المجلد إلى استضافة HTTPS (مثل GitHub Pages).
- بعد فتح الرابط في Chrome على أندرويد: القائمة ⋮ > تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.
- التطبيق يحتاج الإنترنت لتسجيل الدخول إلى Supabase ولتحميل مكتبات الواجهة الخارجية.
- التخزين دون اتصال محدود بملفات واجهة البرنامج فقط؛ لا تدخل بيانات جديدة دون اتصال وتتوقع مزامنتها تلقائيًا.
- يجب اختبار تسجيل الدخول والمزامنة على الاستضافة قبل الاعتماد عليه في بيانات المزرعة.
